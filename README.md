# 💘 心动契约 · Heart Pact

**虚拟恋人互动聊天游戏（网页版）** —— 捏一个专属的 TA，在主界面聊天互动、换装送礼、提升好感度。

## ✨ 玩法一览

1. **开始页**：点「💗 开始游戏」进入捏人（有存档时显示「继续游戏」）
2. **自定义角色（纯自定义，无预设原型）**：
   - 选择性别（男生 / 女生）
   - 从零填写全部资料：**名字、年龄、身高、职业、性格标签、说话方式、背景故事、TA 对你的专属称呼、你的名字**
   - **性格标签 49 个**（含暗黑系：病娇 / 黑化 / 占有欲 / 偏执 / 疯批 / 斯文败类 / 忠犬病娇…），默认折叠显示 16 个，点「展开全部」查看，选中标签收起后仍会显示
   - **说话方式 / 背景故事各带「🎲 生成」按钮**：一键随机生成，也可以自己手写
   - **立绘画廊**：从 17 张 AI 生成动漫立绘中挑选（男女分类，各自只显示同性别立绘），支持「🎲 随机立绘」
3. **进入角色主界面**：屏幕中央展示**立绘**（呼吸浮动动画），顶部 HUD（金币 / 相识天数 / 签到 / 任务）与好感度爱心条，底部香槟金互动 Dock
4. **底部 Dock 互动**（SVG 金线图标）：💬 聊天 · 🎬 约会 · 📱 朋友圈 · 🎁 送礼 · 💗 摸摸头 · 👗 换立绘 · 📞 通话 · 📸 回忆 · 🪞 角色卡
5. **玩法系统**：
   - **🩷 好感度**：聊天、送礼、摸头、约会、朋友圈互动都会提升好感度，升阶有特效与回忆记录
   - **🪙 金币**：通过每日签到、每日任务、朋友圈互动获得；送礼消耗金币
   - **📅 每日签到**：连续签到 7 天奖励递增（20→60 金币），断签重置，签到入口会发光提醒
   - **✅ 每日任务**：聊聊天 / 摸摸头 / 送礼 / 关心 TA 的动态，完成后领取金币
   - **📱 朋友圈**：TA 会发日常动态（深夜会议、值夜班、下雨天、煮面翻车…），你可以点赞（+1 好感）或选择评论（+2 好感），不同选项有不同回应
   - 🎬 约会剧情、📞 来电、📸 回忆相册、🪞 角色卡、🏆 13 枚成就

## ✨ 功能一览

- 🎨 **视觉主题**：《恋与深空》风格——深海夜色底 + 香槟金细线 + 衬线标题 + 底部互动 Dock；星点背景、金线描边卡片、玻璃拟态弹窗、金线图标
- 🖼️ **角色立绘素材**：**17 张 AI 生成现代风动漫立绘**（男生 9 张：冷面总裁/温柔医生/竹马学长/顶流偶像/痞帅调酒师/儒雅总裁/银发偶像/耳机少年/运动系少年；女生 8 张：优雅姐姐/元气少女/御姐上司/时尚学姐/温柔学妹/运动系女孩/甜美主播/神秘御姐），**男女分类**：男生只显示男生立绘、女生只显示女生立绘，角色卡自动分配同性别立绘；全身立绘 + 头像裁切双版本
- 🎲 **一键生成资料**：「🎲 一键生成资料」自动生成名字、年龄、身高、职业、性格、说话风格、背景故事、专属称呼（9 套生成池 × 513 条文案随机组合）；「✨ 换批风格」单独重摇
- 📖 **背景详细资料**：名字、年龄、身高、职业、性格标签、说话风格、背景故事、专属称呼全部可编辑，汇成完整"角色卡"
- 💬 **互动聊天**：AI 深度聊天（推荐开启）或离线台词库；**回复队列化**（连发消息时按顺序逐条回复，不再乱序/堆积）
- 🔔 **TA 会主动找你（像微信一样）**：在首页/聊天页都会主动发消息，首页弹**仿微信新消息通知**（头像+昵称+消息内容，点击直接进入聊天），聊天图标显示未读红点；频率可在设置里选「少 / 正常 / 频繁」
- 🔥 **张力 / 暧昧尺度**：创建角色时可选「高张力（默认）/ 中等暧昧 / 温和纯爱」；高张力通过潜台词双关、身体距离感、感官氛围、占有欲与掌控感、情绪落差钩子制造心跳感
- 💥 **双方大胆程度**：可选「大胆（默认）/ 主动但克制 / 克制」；大胆版=对方**主动出击、直球挑明、当面宣示主权、动作更近一步**，吃醋就明说、想念就明说、想要就明说，同时保持人设（病娇/黑化更危险、温柔型也是温柔包裹的大胆）
- 🎭 **人设语气还原**：性格标签自动映射成语气要求（病娇/黑化/占有欲→偏执占有、毒舌→嘴上不饶人等），还可填「经典台词/语气示例」让 AI 模仿你的专属口吻；系统提示词严格限制 1-2 句、≤60 字、禁止 OOC 与 AI 腔
- ⚠️ **内容边界**：直白露骨的性描写一律不生成，刺激感用暧昧临界、留白与占有欲营造
- 🩷 **好感度系统**：0–100 七段感情（陌生→初识→相熟→心动→暧昧→热恋→挚爱）
- 🌧️ **约会剧情**：6 段互动剧情（雨天同伞/天台看星/一起下厨/照顾生病的你/生日惊喜/告白之夜），含选项分支
- 📞 **来电**：随时给 TA 打电话，有心动台词
- 🎁 **送礼**：咖啡、玫瑰、手写信、围巾、蛋糕、游戏机、许愿星瓶
- 📸 **回忆相册** + 🏆 **10 枚成就徽章**
- 💌 **TA 主动找你**：按时间段发早安晚安、随机心情流转
- 💾 **本地存档**：进度保存在浏览器 localStorage（自动保存，切后台/关页面也会保存）；有存档时开始页「继续游戏」是主按钮，并显示存档信息（角色名/相识天数/好感/金币）
- 🔑 **设置自动保存**：API Key、模型、音效、主动消息等设置改动后**自动保存**（无需点保存按钮），并单独镜像存储在 `xin_dong_qy_settings_v1`——刷新、换角色、开始新游戏都不会丢，只有清除浏览器数据才会丢
- 📦 **存档备份**：设置里可「💾 导出存档备份」（下载 JSON）与「📂 导入存档」，换浏览器/清缓存/换设备后可恢复
- ⚠️ **注意**：存档与网址绑定——`http://localhost:8000` 和 `http://127.0.0.1:8000`、以及直接双击 `index.html` 属于不同存储空间，请始终用同一网址打开；隐私模式/禁用存储会导致无法保存（启动时会提示）

## 🚀 如何运行

### 方式一：直接打开（最简单）
双击 `index.html`，用浏览器打开即可玩。
> AI 聊天需要联网接口；离线对话引擎完全可用。

### 方式二：本地服务器（推荐，手机也能玩）
双击 `start.bat`，或手动执行：
```bash
python -m http.server 8000
```
- 电脑访问：<http://localhost:8000>
- **手机访问**：手机与电脑连同一 Wi-Fi，访问 `http://<电脑IP>:8000`（电脑 IP 可用 `ipconfig` 查询）。
- 手机浏览器建议「添加到主屏幕」，体验接近原生 App。

### 部署到公网
整个目录是纯静态文件，可直接丢到 GitHub Pages / Netlify / Vercel。

## 🤖 AI 聊天（可选，强烈推荐）

让虚拟恋人按你的角色设定实时生成回复，聊天更聪明。

### 配置步骤（游戏内 ⚙️ → 设置）
1. AI 聊天选「**开启**」；
2. 填入 API Key（`sk-…`）；
3. 模型推荐 **`deepseek-flash`**（官方 V4.1 Flash，最快最省、支持图像理解，聊天更顺）；也可填 `deepseek-v4-pro`（上一代旗舰）。注意：API 调用名是 `deepseek-flash`，不是 `deepseek-v4.1-flash`；接口地址默认 `https://api.deepseek.com`（也兼容任意 OpenAI 格式接口）；
4. 可调「**创意程度**」（低=更稳重贴设定，高=更灵动会撩）；
5. 点「**🧪 测试连接**」验证——成功会显示 TA 的试回复。

### 如何获取 API Key
- 前往 [platform.deepseek.com](https://platform.deepseek.com) 注册，在「API Keys」页面创建密钥（新用户通常有免费额度，也可充值）。
- Key 只保存在你自己浏览器的 localStorage，直连官方接口，不经过任何第三方服务器。

### 提示
- 开启 AI 后聊天页会显示「🤖 AI 智脑」徽章；对话仍会正常计算好感度。
- AI 请求失败（断网/余额不足/Key 错误）会自动回落离线台词库，不会中断聊天。
